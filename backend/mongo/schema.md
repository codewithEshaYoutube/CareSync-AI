# CareSync AI — MongoDB Schema

MongoDB stores three categories of schema-flexible, document-oriented data that don't belong in the relational model:
1. **Agent Intelligence** — raw web-scraped content, outbreak news, supplier intelligence
2. **Forecasts** — 48-hour ML-generated time-series predictions per hospital/resource
3. **Chat Context** — full LLM context windows for the AI Copilot

---

## Connection

```
MONGO_URL=mongodb://localhost:27017
MONGO_DB=caresync
```

---

## Collection: `agent_intelligence`

Stores unstructured documents produced by the Bright Data scraping agents.
Each document is a single piece of web intelligence tied to an agent run.

### Document Shape

```json
{
  "_id": ObjectId("..."),
  "agent_id": "d1000000-0000-0000-0000-000000000004",
  "hospital_id": null,
  "data_type": "outbreak_news",
  "source_url": "https://who.int/...",
  "title": "WHO Alert: Seasonal Oxygen Demand Surge Expected in Northern India",
  "content": "Full article text or structured JSON from web scrape...",
  "scraped_at": ISODate("2026-05-27T10:00:00Z"),
  "tags": ["oxygen", "shortage", "northern-india", "who"],
  "region": "Delhi NCR",
  "relevance_score": 0.87,
  "processed": false
}
```

### Field Reference

| Field            | Type            | Required | Description                                               |
|------------------|-----------------|----------|-----------------------------------------------------------|
| `_id`            | ObjectId        | auto     | Document identifier                                       |
| `agent_id`       | string (UUID)   | yes      | FK reference to `agents.id` in PostgreSQL                 |
| `hospital_id`    | string (UUID)   | no       | Hospital context if scrape is facility-specific           |
| `data_type`      | string (enum)   | yes      | `outbreak_news` \| `supplier_intelligence` \| `web_scrape` \| `inventory_analysis` |
| `source_url`     | string          | yes      | Origin URL of the scraped content                         |
| `title`          | string          | no       | Page/article title                                        |
| `content`        | string or object| yes      | Raw text or structured JSON from scraper                  |
| `scraped_at`     | Date            | yes      | When the scrape was performed                             |
| `tags`           | string[]        | no       | Classification tags for filtering                         |
| `region`         | string          | no       | Geographic region of relevance                            |
| `relevance_score`| float (0–1)     | no       | AI-computed relevance to current operational context      |
| `processed`      | boolean         | yes      | Whether this doc has been ingested by downstream agents   |

### Indexes

```javascript
db.agent_intelligence.createIndex({ "agent_id": 1 })
db.agent_intelligence.createIndex({ "data_type": 1 })
db.agent_intelligence.createIndex({ "scraped_at": -1 })
db.agent_intelligence.createIndex({ "region": 1, "data_type": 1 })
db.agent_intelligence.createIndex({ "processed": 1, "scraped_at": -1 })
// Full-text search on content and title
db.agent_intelligence.createIndex(
  { "title": "text", "content": "text", "tags": "text" },
  { name: "text_search_idx" }
)
```

### Query Patterns

```python
# Unprocessed outbreak news for a region
db.agent_intelligence.find({
    "data_type": "outbreak_news",
    "region": "Delhi NCR",
    "processed": False
}).sort("scraped_at", -1).limit(10)

# Full-text search
db.agent_intelligence.find({ "$text": { "$search": "oxygen shortage northern india" } })
```

## Collection: `forecasts`

48-hour predictive forecasts generated by the ML forecasting pipeline.
One document per (hospital, resource, generation run).

### Document Shape

```json
{
  "_id": ObjectId("..."),
  "hospital_id": "b1000000-0000-0000-0000-000000000002",
  "resource_id": "c1000000-0000-0000-0000-000000000001",
  "resource_name": "oxygen",
  "hospital_name": "AIIMS New Delhi",
  "forecast_values": [
    { "timestamp": ISODate("2026-05-27T11:00:00Z"), "predicted_value": 22.5, "confidence": 0.91 },
    { "timestamp": ISODate("2026-05-27T12:00:00Z"), "predicted_value": 19.8, "confidence": 0.88 },
    ...
  ],
  "generated_at": ISODate("2026-05-27T10:00:00Z"),
  "model_version": "caresync-forecast-v1.2",
  "horizon_hours": 48,
  "input_features": {
    "historical_window_hours": 168,
    "seasonality": true,
    "outbreak_signal": 0.34
  }
}
```

### Field Reference

| Field              | Type          | Required | Description                                              |
|--------------------|---------------|----------|----------------------------------------------------------|
| `_id`              | ObjectId      | auto     |                                                          |
| `hospital_id`      | string (UUID) | yes      | FK reference to `hospitals.id`                           |
| `resource_id`      | string (UUID) | yes      | FK reference to `resources.id`                           |
| `resource_name`    | string        | yes      | Denormalized for fast reads                              |
| `hospital_name`    | string        | yes      | Denormalized for fast reads                              |
| `forecast_values`  | object[]      | yes      | Array of `{timestamp, predicted_value, confidence}`      |
| `generated_at`     | Date          | yes      | When the forecast was generated                          |
| `model_version`    | string        | yes      | Version identifier for reproducibility                   |
| `horizon_hours`    | int           | yes      | Forecast window (default 48)                             |
| `input_features`   | object        | no       | Feature flags / context used during model inference      |

### Indexes

```javascript
db.forecasts.createIndex({ "hospital_id": 1, "resource_id": 1, "generated_at": -1 })
db.forecasts.createIndex({ "generated_at": -1 })
// TTL — auto-delete forecasts older than 7 days
db.forecasts.createIndex({ "generated_at": 1 }, { expireAfterSeconds: 604800 })
```

### Query Patterns

```python
# Latest forecast for a hospital/resource pair
db.forecasts.find_one(
    {"hospital_id": hospital_id, "resource_id": resource_id},
    sort=[("generated_at", -1)]
)
```

## Collection: `chat_context`

Full LLM context windows for each chat session.
Stored here (not PostgreSQL) because context arrays can be large and schema-variable.

### Document Shape

```json
{
  "_id": ObjectId("..."),
  "session_id": "uuid-of-chat-session",
  "system_prompt": "You are the CareSync AI Procurement Agent...",
  "context_window": [
    {
      "role": "user",
      "content": "What's the oxygen situation in Delhi NCR?",
      "timestamp": ISODate("2026-05-27T10:00:00Z")
    },
    {
      "role": "assistant",
      "content": "Oxygen levels at AIIMS New Delhi are critically low at 24%...",
      "timestamp": ISODate("2026-05-27T10:00:05Z"),
      "tokens_used": 312
    }
  ],
  "hospital_context": {
    "hospital_id": "b1000000-0000-0000-0000-000000000002",
    "hospital_name": "AIIMS New Delhi",
    "current_metrics": { "oxygen": 24.0, "icu": 92.1, "pharma": 61.0 }
  },
  "updated_at": ISODate("2026-05-27T10:05:00Z"),
  "total_tokens": 1248
}
```

### Field Reference

| Field              | Type          | Required | Description                                               |
|--------------------|---------------|----------|-----------------------------------------------------------|
| `_id`              | ObjectId      | auto     |                                                           |
| `session_id`       | string (UUID) | yes      | FK reference to `chat_sessions.id` in PostgreSQL          |
| `system_prompt`    | string        | yes      | System prompt injected at conversation start              |
| `context_window`   | object[]      | yes      | Full message history for LLM context                      |
| `hospital_context` | object        | no       | Snapshot of hospital state injected into context          |
| `updated_at`       | Date          | yes      | Last message timestamp                                    |
| `total_tokens`     | int           | no       | Running token count for budget management                 |

### Indexes

```javascript
db.chat_context.createIndex({ "session_id": 1 }, { unique: true })
db.chat_context.createIndex({ "updated_at": -1 })
// TTL — auto-delete chat contexts after 30 days of inactivity
db.chat_context.createIndex({ "updated_at": 1 }, { expireAfterSeconds: 2592000 })
```

### Query Patterns

```python
# Load context for an active session
db.chat_context.find_one({"session_id": session_id})

# Upsert after each message
db.chat_context.update_one(
    {"session_id": session_id},
    {"$set": {"context_window": messages, "updated_at": datetime.utcnow(), "total_tokens": count}},
    upsert=True
)
```

## Initialization Script

Run once to create indexes on a fresh database:

```python
# backend/mongo/init_indexes.py
from pymongo import MongoClient, TEXT, ASCENDING, DESCENDING
import os

client = MongoClient(os.getenv("MONGO_URL", "mongodb://localhost:27017"))
db = client[os.getenv("MONGO_DB", "caresync")]

# agent_intelligence
ai = db.agent_intelligence
ai.create_index("agent_id")
ai.create_index("data_type")
ai.create_index([("scraped_at", DESCENDING)])
ai.create_index([("region", ASCENDING), ("data_type", ASCENDING)])
ai.create_index([("processed", ASCENDING), ("scraped_at", DESCENDING)])
ai.create_index([("title", TEXT), ("content", TEXT), ("tags", TEXT)], name="text_search_idx")

# forecasts
fc = db.forecasts
fc.create_index([("hospital_id", ASCENDING), ("resource_id", ASCENDING), ("generated_at", DESCENDING)])
fc.create_index([("generated_at", DESCENDING)])
fc.create_index([("generated_at", ASCENDING)], expireAfterSeconds=604800)  # 7-day TTL

# chat_context
cc = db.chat_context
cc.create_index("session_id", unique=True)
cc.create_index([("updated_at", DESCENDING)])
cc.create_index([("updated_at", ASCENDING)], expireAfterSeconds=2592000)   # 30-day TTL

print("MongoDB indexes created.")
```
